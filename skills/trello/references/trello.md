# Trello 보드 규약

목적: trello 스킬이 조회 없이 쓰는 id와 카드·댓글 형식을 둔다. 값은 사용자에게 받아 채운다.

## 고정 정보

| 항목 | id |
|---|---|
| 보드 <이름> | |
| 담당 멤버 <이름> | |
| 라벨 <이름> | |
| 기본 리스트 <이름> | |

## 카드 추가 기본값

- members: 담당 멤버
- labels: <라벨 목록>
- 리스트: 기본 리스트

## 카드 형식

- 제목: `<형식. 카드 번호를 쓰면 (<카드 번호>)처럼 자리를 표시>`
- 본문:

  ```markdown
  <본문 템플릿>
  ```

## 완료 댓글 형식

```markdown
<댓글 템플릿 — 작업 / 변화 / 검증 등 보드 관례대로>
```
