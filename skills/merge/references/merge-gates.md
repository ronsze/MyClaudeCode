# 프로젝트 사전 검사 형식

목적: merge 스킬이 공통 게이트에 더해 수행할 프로젝트 고유 브랜치별 사전 검사를 `.claude/merge-gates.md`에 적는 형식을 정한다. 이 파일을 그대로 복사해 행을 채운다.

- 판정 방법은 셸 명령 또는 diff에서 기계적으로 확인되는 조건으로 적는다. 사람 판단이 필요한 항목은 `보고`로만 둔다.
- 근거 열은 그 규칙의 정본(문서 절·결정 기록)을 가리킨다. 정본이 없는 규칙은 넣지 않는다.

```markdown
# 병합 사전 검사

| # | 항목 | 판정 방법 | 판정(차단|보고 — 상세) | 근거 |
|---|---|---|---|---|
| P1 | <항목> | <명령 또는 diff 조건> | <차단 또는 보고 — 결과에 적을 것> | <문서 절> |
```
